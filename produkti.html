Mūsu mācību programmas

Izvēlies sev piemērotāko Linux distributīvu un sāc savu ceļu IT pasaulē. Visi kursi ilgst 3 mēnešus.

1. Linux Mint: Ideāls sākums

Labākā izvēle tiem, kas pāriet no Windows. Stabils, saprotams un vizuāli pievilcīgs. Iemācies sistēmas pamatus bez stresa.

Ilgums: 3 mēneši
Cena: 450€ + PVN

2. Ubuntu: Standarts un jauda

Vispopulārākais Linux pasaulē. Lieliski piemērots gan darbam, gan izklaidei. Apgūsti plašāko kopienu un modernāko programmatūru.

Ilgums: 3 mēneši
Cena: 450€ + PVN

3. Manjaro: Ātrums un jaunumi

Arch bāzēta sistēma, kas vienmēr piedāvā jaunākās programmu versijas. Dinamiskiem lietotājiem, kuri vēlas būt tehnoloģiju priekšgalā.

Ilgums: 3 mēneši
Cena: 450€ + PVN

4. Debian: Stabilitāte

Sistēma profesionāļiem. Uzzini, kā darbojas Linux sirds, un iemācies konfigurēt servera līmeņa drošību un stabilitāti.

Ilgums: 3 mēneši
Cena: 450€ + PVN
